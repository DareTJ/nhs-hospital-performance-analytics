# Data sources and release versions

I use published provider-month aggregates from NHS England's Monthly A&E Attendances and Emergency Admissions collection, covering September 2024 to August 2026. The supplied CSVs contain reporting periods, organisation codes and names, and aggregate counts. The release contains no patient-level records. The source and the derived snapshot are attributed to NHS England. The website permits reuse of eligible information under the Open Government Licence, subject to its exclusions. The licence governs the eligible source data and its adapted data, with attribution. ## Frozen extract

I compared each local input with the public NHS England file on 25 November 2026. Twenty-three files matched byte for byte. The September 2024 official CSV contained five unnamed trailing columns and one column headed `a`, all empty for every data row. Removing those six columns reproduced all 22 local columns in the same order, with identical headers and values across all 198 data rows. The local extract keeps its existing name for SQL source lineage.

April to August 2026 uses the original publication files. NHS England's annual collection page now links to revised releases for those five months. I compared the original and revised provider rows by normalised organisation code across all 18 counts. At least one count changed for 2 of 190 providers in April, 2 of 192 in May, 2 of 192 in June, 3 of 191 in July and 3 of 191 in August. No codes entered or left those five monthly provider sets. The revised August national attendance total was 2,344,278 compared with 2,342,959 in the frozen extract. [2026/27 collection and revised releases](https://www.england.nhs.uk/statistics/statistical-work-areas/ae-waiting-times-and-activity/ae-attendances-and-emergency-admissions-2026-27/) · [November revision commentary](https://www.england.nhs.uk/statistics/wp-content/uploads/sites/2/2026/11/Statistical-commentary-October-2026-DW43tf-1.pdf)
